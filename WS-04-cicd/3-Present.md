# WS-04 · Present — Demo

**เวลา:** 5 นาทีต่อกลุ่ม

## ขั้นตอนการ Demo

| ลำดับที่ | ขั้นตอน | เกณฑ์ผ่าน |
|---|---|---|
| 1 | เจ้าของ repository เปิด Settings → Rules → Rulesets → `main-gate` | ruleset เป็น Active ใช้กับ default branch และ bypass list ว่าง |
| 2 | สร้าง commit ว่างบน `main` ในเครื่องแล้วรัน `git push origin main` ต่อหน้าผู้ตรวจ | push ถูกปฏิเสธด้วยข้อความ `GH013: Repository rule violations found` |
| 3 | เปิด PR break-it-live จากขั้นตอนที่ 6 ของ lab (PR ที่ลบเงื่อนไขของ R2 และยังเปิดอยู่) | CI เป็นสีแดงที่ขั้น `npm test` และปุ่ม merge กดไม่ได้ |
| 4 | เปิด `REVIEW.md` แล้วชี้ 1 ข้อที่มาจากประสบการณ์ของกลุ่ม | อธิบายได้ว่าข้อนั้นป้องกันปัญหาใดที่กลุ่มเคยพบ |
| 5 | เปิด PR ของ R2 ใน `03-cancel` ที่ merge แล้ว | comment ผลการ AI review ระบุรอบและระดับความรุนแรงตาม `REVIEW.md` ทุกข้อ |
| 6 | เปิดตาราง "ผลการ AI review ที่กลุ่มไม่ทำตาม" ใน `evidence/ws-04.md` เลือก 1 ข้อแล้วอธิบาย | อธิบายด้วยคำของกลุ่มเองได้ว่าเหตุใดจึงไม่ทำตาม |
| 7 | รัน `npx vitest run -t "R2"` | test ผ่านทั้งหมด และมี test ที่ตรวจว่าผู้ลงทะเบียนก่อนในคิวสำรองเป็นผู้ได้ที่นั่ง |
