# WS-06 · Present — Demo

**เวลา:** 5 นาทีต่อกลุ่ม

## ขั้นตอนการ Demo

| ลำดับที่ | ขั้นตอน | เกณฑ์ผ่าน |
|---|---|---|
| 1 | เปิด Live URL เข้าสู่ระบบเป็นผู้เข้าร่วมที่ผู้ตรวจเลือกจาก seed data แล้วเปิดหน้าการลงทะเบียนของฉัน | แสดงเฉพาะรายการของผู้ใช้คนนั้น พร้อมสถานะ |
| 2 | ส่งคำขอลงทะเบียนไปที่ Live URL ด้วย `curl` และ header `x-user-id` โดยไม่มี cookie | ได้ `401` |
| 3 | รัน `docker compose up -d --build --wait` แล้ว `npm run e2e` ในเครื่อง | test ของ journey ผ่าน |
| 4 | เปิด PR break-it-live จากขั้นตอนที่ 6.2 ของ lab (PR ที่ไม่บันทึกสถานะของผู้ที่ได้เลื่อนจากคิวสำรองและยังเปิดอยู่) | job `e2e` เป็นสีแดง และปุ่ม merge กดไม่ได้ |
| 5 | เปิด trace ของ test ที่ไม่ผ่านใน `playwright-report` ของ PR นั้น | ชี้ขั้นที่ไม่ผ่านได้ และบอกได้ว่าหน้าจอแสดงอะไรแทนที่ควรเห็น |
| 6 | เปิด comment รายงานของ verifier ใน PR ของหน้าจอ เลือก 1 ข้อที่ไม่ตรงกับ spec | อธิบายได้ว่า verifier พบอย่างไร และกลุ่มทำอะไรกับข้อนั้น |
| 7 | เข้าสู่ระบบบน Live URL เป็นผู้เข้าร่วม แล้วพิมพ์ URL ของหน้าจัดการกิจกรรมเอง | เปิดหน้านั้นไม่ได้ตามที่ spec กำหนด |
