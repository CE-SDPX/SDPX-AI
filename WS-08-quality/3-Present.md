# WS-08 · Present — Demo

**เวลา:** 5 นาทีต่อกลุ่ม

## ขั้นตอนการ Demo

| ลำดับที่ | ขั้นตอน | เกณฑ์ผ่าน |
|---|---|---|
| 1 | เข้าสู่ระบบบน Live URL ด้วย `curl` เป็นผู้เข้าร่วม แล้วเรียก endpoint รายชื่อผู้ลงทะเบียนของกิจกรรมหนึ่ง | ได้ status code ที่ปฏิเสธตาม spec ไม่ได้รายชื่อ |
| 2 | รัน `docker compose up -d --build --wait` แล้ว `npx playwright test access` ในเครื่อง | test ผ่านทั้งหมด และชื่อ test ขึ้นต้นด้วยรหัสข้อใน checklist |
| 3 | เปิด PR break-it-live จากขั้นตอนที่ 5 ของ lab (PR ที่ลบการตรวจเจ้าของกิจกรรมและยังเปิดอยู่) | job `e2e` เป็นสีแดงที่ test ของ S3 และปุ่ม merge กดไม่ได้ |
| 4 | ผู้ตรวจเลือก 1 ข้อใน `docs/security-checklist.md` | กลุ่มเปิดหลักฐานของข้อนั้นได้ และหลักฐานพิสูจน์ข้อนั้นจริง |
| 5 | เปิดแท็บ Security ของ repository | ไม่มี alert ระดับ high หรือ critical ที่เปิดค้างโดยไม่มีการจัดการ |
| 6 | เปิด issue `Security review WS-08` เลือก 1 ข้อ Important | มี PR ที่เพิ่ม test ก่อนแก้ code หรือมี comment ยืนยันว่าไม่ใช่ปัญหาพร้อมผลการลอง |
| 7 | ผู้ตรวจเลือก 1 บทเรียนใน `LESSONS.md` | กลุ่มเปิดสิ่งที่ป้องกันบทเรียนนั้นได้ และอธิบายได้ว่าจับปัญหาเดิมได้อย่างไร |
