|---|---|---|
| 1 | เปิด Live URL ของกลุ่ม | ผู้ตรวจเปิดบนเครื่องของตนเองแล้วเห็นหน้าแรกของระบบ |
| 2 | ผู้ตรวจกำหนดข้อความหัวเรื่องใหม่ กลุ่มแก้ code, commit และ push ผู้ตรวจจดเวลาที่ใช้ | ข้อความที่ผู้ตรวจกำหนดขึ้นบนเว็บจริง และ CI ของ commit นั้นเป็นสีเขียว |

| 7 | เปิดรายการ Pull requests ที่ merge แล้ว | สมาชิกทุกคนเป็นผู้เปิด PR อย่างน้อย 1 รายการ |
