# WS-01 · Present — Deploy Loop

**เวลา:** 10 นาทีต่อกลุ่ม
**รูปแบบ:** ผู้สอนสุ่มสมาชิก 1 คนจากกลุ่มเป็นผู้นำเสนอ โดยไม่แจ้งล่วงหน้า
สมาชิกทุกคนจึงควรเข้าใจงานของกลุ่มทั้งหมด ไม่ต้องเตรียม slide ให้สาธิตจากหน้าจอโดยตรง

---

## 1. สาธิต (5 นาที)

1. เปิด Live URL และแสดงว่าระบบทำงานได้
2. เปิด repository แสดง `AGENTS.md` และ `evidence/ws-01.md`
3. **Break-it-live:** แก้ code ให้ build ไม่ผ่าน แล้ว push เข้า branch และเปิด PR
   - แสดงว่า CI ไม่ผ่าน
   - แสดงว่าเว็บจริงยังคงเป็นเวอร์ชันเดิม
   - ปิด PR นั้นโดยไม่ merge

หากเวลาไม่พอ ให้เปิดลิงก์ CI run ที่ไม่ผ่านซึ่งบันทึกไว้ใน `evidence/ws-01.md` แทน

---

## 2. คำถาม (5 นาที)

ผู้สอนถามคำถาม 3 ข้อ ซึ่งใช้โครงเดียวกันทุกบท

| หัวข้อ | คำถาม |
|---|---|
| **แสดง** | loop ของกลุ่มตรวจพบอะไรได้บ้าง และตรวจไม่พบอะไร |
| **อธิบาย** | เลือกกติกา 1 ข้อใน `AGENTS.md` แล้วอธิบายว่าใส่ไว้เพื่อป้องกันปัญหาใด |
| **ตัดสินใจ** | AI เสนออะไรที่กลุ่มไม่รับ และเพราะเหตุใด |

คำถามเพิ่มเติมที่ผู้สอนอาจใช้

- หากสมาชิกใหม่จะ clone repository นี้ไปรัน ต้องทำอะไรบ้าง
- commit-to-live time ของกลุ่มคือเท่าใด ขั้นตอนใดใช้เวลามากที่สุด
- หาก deploy ครั้งถัดไปทำให้หน้าเว็บใช้งานไม่ได้ กลุ่มจะทราบเมื่อใด
- หากต้องการทราบว่าใครเป็นผู้อนุมัติการเปลี่ยนแปลงล่าสุดบนเว็บจริง จะดูได้จากที่ใด

---

## 3. เกณฑ์การให้คะแนน (1.25 คะแนน)

พิจารณาจากการสาธิตและคำตอบทั้ง 3 ข้อรวมกัน แล้วให้คะแนนเพียงระดับเดียว

| คะแนน | เกณฑ์ |
|---|---|
| **0** | สาธิต break-it-live ไม่ได้ หรืออธิบายงานของกลุ่มไม่ได้ |
| **0.75** | สาธิตได้ แต่การอธิบายหรือเหตุผลในการตัดสินใจยังไม่ชัดเจน |
| **1.25** | สาธิตได้ อธิบายได้ด้วยคำพูดของตนเอง และให้เหตุผลเรื่องการตัดสินใจที่เฉพาะเจาะจงกับระบบของกลุ่ม |

---

## หมายเหตุสำหรับผู้สอน

- สุ่มผู้นำเสนอต่อหน้าชั้นเรียน เช่น ใช้ random function
- หากผู้ถูกสุ่มตอบไม่ได้ สมาชิกคนอื่นช่วยเสริมได้ แต่คะแนนสูงสุดของกลุ่มในบทนี้คือ 0.75
- คำถาม "หากระบบใช้งานไม่ได้ จะทราบเมื่อใด" จะถูกถามซ้ำในทุกบท เพื่อให้นักศึกษาคุ้นเคยกับการคิดเรื่องขั้นตรวจสอบตั้งแต่สัปดาห์แรก
- ประเด็นที่ควรชี้ให้เห็น: Vercel และ Render ไม่ได้รอผลของ CI หาก push code ที่ build ได้แต่ lint ไม่ผ่านเข้า `main` โดยตรง เว็บจริงจะยังถูก deploy ข้อจำกัดนี้จะแก้ด้วย branch protection ใน WS-04
