# WS-02 · Before — Spec Loop

สัปดาห์นี้แต่ละกลุ่มจะเขียนว่าระบบต้องทำอะไร ก่อนที่จะให้ AI เขียน code ของ feature แรกในบทถัดไป
เป้าหมายคือมีเอกสารที่ทั้งคนและ AI อ่านแล้วเข้าใจตรงกัน และมีส่วนที่เครื่องตรวจได้

เนื้อหาในหน้านี้จะไม่มีการอธิบายซ้ำในชั้นเรียน
ช่วงต้นคาบจะมีการสุ่มถามความหมายของคำในส่วน A
เวลาที่ควรใช้เตรียมตัวทั้งหมดไม่เกิน 1.5 ชั่วโมง

---

## A. Keywords

| Keyword | ความหมายโดยย่อ |
|---|---|
| Intent | สิ่งที่ผู้ใช้ต้องการและเหตุผล เขียนด้วยคำของผู้ที่ต้องการ ก่อนลงรายละเอียดทางเทคนิค |
| Specification (spec) | เอกสารที่ระบุว่าระบบต้องทำอะไรในแต่ละกรณี ละเอียดพอที่จะเขียน test ตรวจได้ |
| Edge case | กรณีที่อยู่ตรงขอบของกฎ เช่น ที่นั่งเหลือ 1 ที่ หรือยกเลิกตอนเหลือเวลา 24 ชั่วโมงพอดี |
| HTTP status code | ตัวเลขที่ server ตอบกลับเพื่อบอกผลของคำขอ เช่น 201 สร้างสำเร็จ, 404 ไม่พบ, 409 ขัดกับสถานะปัจจุบัน |
| OpenAPI | รูปแบบไฟล์มาตรฐานสำหรับอธิบาย API ว่ามี endpoint ใด รับและตอบข้อมูลอะไร ซึ่งเครื่องอ่านและตรวจได้ |
| ADR (Architecture Decision Record) | เอกสารสั้นที่บันทึกการตัดสินใจทางเทคนิค 1 เรื่อง พร้อมทางเลือกที่พิจารณาและเหตุผล |

---

## B. ติดตั้งและทดสอบ

| เครื่องมือ | คำสั่งทดสอบ | ผลที่ต้องได้ |
|---|---|---|
| เครื่องมือจาก WS-01 | `npm run build` ใน repository ของกลุ่ม | build ผ่าน |
| Redocly CLI (ไม่ต้องติดตั้ง ใช้ผ่าน `npx`) | `npx --yes @redocly/cli@2 --version` | แสดงเลขรุ่นที่ขึ้นต้นด้วย 2 |
| VS Code extension: YAML (Red Hat) | เปิดไฟล์ `.yaml` ใดก็ได้ | เห็นสีของ syntax และมีเส้นใต้เมื่อย่อหน้าผิด |

การรัน `npx` ครั้งแรกจะดาวน์โหลด Redocly CLI ซึ่งใช้เวลาสักครู่ ครั้งต่อไปจะเร็วขึ้น

## C. เตรียมใน repository

- [ ] CI ของกลุ่มบน `main` เป็นสีเขียว และ Live URL ยังเปิดได้
- [ ] อ่าน `PROJECT.md` หัวข้อ 2–4 แล้วจดคำถาม 1 ข้อเกี่ยวกับกฎ R1–R6 ที่ยังไม่ชัด ในรูปแบบ "ถ้า ... ระบบควรทำอย่างไร" เพื่อนำมาใช้ในขั้นตอนที่ 3 ของ lab
- [ ] เปิด AI agent ใน repository ของกลุ่มแล้วสั่งงานต่อไปนี้

  ```
  Read PROJECT.md. List situations where rules R1–R6 do not say
  what the system should do. Do not answer them.
  ```

  สิ่งที่ต้องจด (ไม่ต้อง commit)
  - กรณีที่ AI พบ แต่ตนเองไม่ได้นึกถึง
  - กรณีที่ตนเองนึกถึง แต่ AI ไม่พบ

หากติดตั้งไม่สำเร็จ ให้บันทึกข้อความ error ไว้ และแจ้งผู้สอนภายใน 5 นาทีแรกของคาบ
