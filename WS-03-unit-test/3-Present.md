# WS-03 · Present — Demo

**เวลา:** 5 นาทีต่อกลุ่ม

## ขั้นตอนการ Demo

| ลำดับที่ | ขั้นตอน | เกณฑ์ผ่าน |
|---|---|---|
| 1 | ผู้ตรวจเลือกกฎ 1 ข้อจาก R1, R3, R4 หรือ R5 กลุ่มเปิด PR ของกฎนั้น | commit ที่เพิ่ม test มี CI สีแดง และอยู่ก่อน commit ที่เพิ่ม code ซึ่งมี CI สีเขียว |
| 2 | รัน `npx vitest run -t "[รหัสกฎ]"` ของกฎที่ผู้ตรวจเลือก | test ผ่านทั้งหมด และมีอย่างน้อย 1 test ที่เป็นค่าขอบตาม spec |
| 3 | ผู้ตรวจชี้ 1 บรรทัดใน code ของกฎนั้น กลุ่มแก้ให้ผิดในเครื่องแล้วรัน `npm test` | มี test ไม่ผ่านอย่างน้อย 1 ข้อ |
| 4 | เปิด `docs/features/02-register/plan.md` ที่รายการ test ของกฎนั้น | ชื่อ test ในแผนตรงกับชื่อ test ที่รันในขั้นตอนที่ 2 |
| 5 | เปิด `docs/adr/ADR-002-layering.md` แล้วอธิบาย | บอกได้ว่าทางเลือกที่ไม่ได้เลือกคืออะไร และเหตุใดจึงไม่เลือก |
| 6 | เรียก endpoint ลงทะเบียน 2 ครั้งด้วยผู้ใช้คนเดียวกัน | ครั้งที่สองได้ status code และ error code ของ R3 ตาม spec |
| 7 | เปิด PR ที่ลบเงื่อนไขของ R5 และปิดแล้ว (เตรียมไว้ก่อน) | ผู้ตรวจเห็น CI สีแดงที่ขั้น `npm test` |
